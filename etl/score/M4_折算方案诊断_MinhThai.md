用户提问：**「Minh Thai 折算后排名还是很高，这合理吗，还是有更好的处理方式」**

**诊断结论：当前口径在语义上确实有缺陷，但缺陷不在「折算不够狠」，而在「折算的对象不对」。**

| 层面 | 结论 |
|---|---|
| 是否合理 | **半合理**。时代折算 f 已经把 21.23 → 5.09（−76%），方向正确；但剩下的 5.09 分仍建立在一个**语义错误**之上 |

## 2. 现有时代折算为什么不够

f(y) = ln(1+N(y)) / ln(1+N(基准年))，N = 累计注册人数。

| 年代 | f | 说明 |
|---|---:|---|
| 1982 | 0.1927 | |
| 1990–2002 | 0.2382 | **停滞期被当成「90 年代」来折算** |
| 2003 | 0.3351 | |
| 2005 | 0.4953 | |
| 2010 | 0.7340 | |
| 2026 | 1.0000 | |

**问题**：f 用的是**全站注册人数**，它回答的是「当年整个魔方运动有多大规模」。
但 M4 的席位数（top-10）是一个**相对概念** —— 只有当候选池大于 10 人时，「前十」才有筛选意义。

- 1982 年：19 人 → 前十 ≈ 「前 19 人里的前 10」，但这 10 人之间水平差距巨大（2.295s 到 5.016s），**且此后 21 年无人挑战**
- 2010 年：5,998 人 → 前十是真正的世界前十

**f 无法识别这个差别**，因为 f 只看「全站人数」，不看「本项目当年的活跃人数」。

## 4. 与 M1 的一致性问题（重要的收敛论据）

**M1（纪录持有价值）**对 Minh Thai 这条 21.2 年的三阶持有段给 **0 分** ——
原因是「阶梯首段 r=0」：他是历史上第一条三阶 WR，没有前值可比，G=0 → 整段 0 分。
（这已记录在 M1 封存文件的「已知边界」里。）

**M4（统治力）现状**却给他 **5.0935 分**（全站 #30）。

> **同一个客观事实（21.2 年的三阶第一），M1 判 0 分、M4 判 5.09 分。**
> 两个模型对同一段历史给出矛盾评价，说明至少有一个的口径需要修正。

加入竞争密度折算后：
- M4 给 Minh Thai **0.3266**（只剩 1982 年 210 天 + 2003 年 235 天的有效竞争期）
- 与 M1 的 0 分**方向一致**（虽然数值不同，但语义上都是「这段不构成统治力」）

## 7. 建议 → **✅ 已采纳（2026-10-25）**

**采用方案 F**，理由：
1. **极精准**：Top25 逐位不变，只动停滞期占位者
2. **极可解释**：「当年这个项目没有人参赛 → 当年的世界排名没有意义」—— 一句话说得清
3. **与 M1 收敛**：不再与 M1 对同一段历史给出矛盾评价
4. **无新旋钮**：不引入需要拍脑袋的阈值

如果后续希望进一步精细化，可叠加方案 C 的密度门槛（ref=10），但收益很小、解释成本更高。

## 9. 已知边界

1. **WCA 口径的限制**：1982–2002 年 WCA 之外确有大量比赛，但不在数据里。
   M4 只能按 WCA 口径判断；若认为「无 WCA 记录 ≠ 无竞争」，则方案 F 会低估早期。
   **但这恰恰是问题所在**：M4 的分值应当只在有可比数据时产生，否则「世界第一」就成了自封的。
2. **「活跃人数」用单次成绩参与人数作代理**，对平均轨道是近似（平均赛道的人也是同一批人）。
3. **方案 F 未处理「弱竞争」**：如 2003 年三盲只有 3 人参赛 —— 该年席位仍按 f(2003)=0.3351 计分，
   未被额外折减。这是已知的不彻底处（方案 C 可覆盖）。
