## 1. 唯一权威口径

```
M6 = Σ_events min( gain, 0.5 )        gain = ln(前值 / 新值)
  · 仅 WR 链条（WCA regional_*_record 标记 = 'WR' 的完整刷新序列）
  · gain 截顶 0.5（≈ +65%；全级别实测 p99=1.29，截顶只影响尾部 1%）
  · 无人数折算、无时代折算；自我刷新也计（连续刷是真实力度）
  · 成绩归一：time(ms) 直接比 / number(步数) 直接比 / multi 解码 cost
    三种 format 统一「越小越强」，ln(prev/new) 跨 format 可比
  · 链条首段（各项目/轨首条 WR）无前值可比 → 天然无 gain（Minh Thai 得 0 分，
    「打得狠」需要参照物；他的「守得稳」由 M1-F2 计分，两维分工互补）
```

## 5. ★ 已知代价：×M1-F2 = 0.58 的机制（不是缺陷，是物理）

**时代分层检验**（按首次 WR 年代分桶，桶内 ρ(M6, M1-F2)）：
2005–09 桶 0.616 / 2010–14 桶 0.626 / 2015–19 桶 0.692 / 2020–24 桶 0.467 —— **桶内不降**。

→ 0.58 **不是时代混杂，是真实的人层面机制**：跳得越远 → 后人要追平越难 → 守得越久。
「打得狠」与「守得稳」在 WR 层面结构性联动，两维不可能完全正交。
这是采纳 M6-F2 的已知代价；六维总分合成时按 0.58 的重叠预期做权重折算。
