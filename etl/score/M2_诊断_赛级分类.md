# M2 诊断 · 赛级分类与口径

> 2026-10-24｜数据快照 2026-10-15｜M1 已封存为 M1-F1
> 结论：**M2 现行的排序几乎是错的**，根因是一个赛级分类 bug，不是参数问题。

---

## 0 一句话

`etl/build.js:294` 把 championships 表里所有「非世界锦标赛」的冠军赛一律当成洲际赛，
于是 **876 场国家锦标赛全部按洲际赛（0.7 权重）计入 M2**，占 M2 领奖台的 **93%**。

---

## 1 现行口径（代码级还原）

```js
// etl/build.js:682-687
const placeW = (pos) => pos === 1 ? 1 : (pos === 2 ? 0.6 : 0.4);
const tier   = WC ? 1.0 : (CC ? 0.7 : 0.4);

// M2 = Σ_领奖台  placeW(名次) × 赛级权重     赛级 = WC 或 CC
// M3 = Σ_领奖台  placeW(名次) × 0.4          赛级 = NC 或 OP
```

即：**只看名次（1/2/3）和赛级（世界/洲/其他），三项乘完直接相加，无其他修正。**

---

## 2 根因：国家锦标赛被当成洲际赛

`WCA_export_championships.tsv` 的 `championship_type` 只有三类取值：

| 类型 | 含义 | 赛事数 | 决赛领奖台 |
|---|---|---|---|
| `world` | 世界锦标赛 | **12** | 574 |
| `_Europe` / `_Asia` / `_South America` / `_Oceania` / `_North America` / `_Africa` / `greater_china` | 洲际 / 区域锦标赛 | **43** | 1,825 |
| `SE` / `IT` / `US` / `HU` … （国家 ISO2 代码） | 国家锦标赛 | **876** | 32,146 |

而 `build.js:294` 写的是：

```js
const t = (r.championship_type || '').toLowerCase();
if (t === 'world') champWC.add(r.competition_id);
else champCC.add(r.competition_id);        // ← 876 场国家锦标赛全进了 CC
```

**实证**（Feliks 的一条领奖台）：

```
CC | 2009 | New Zealand Championships 2009 | 333 | pos 1
```

新西兰国家锦标赛被标成洲际赛。

### 后果

| | 现行 | 真实 |
|---|---|---|
| 标为 CC 的领奖台 | 约 34,000 | **1,825** |
| 其中属于洲际赛的比例 | — | **5.34%** |
| 标为 WC 的领奖台 | 564 | 574 |

## 3 修复后的真实排序

只改赛级分类（权重、公式一律不动）：

| # | 选手 | 现行 M2 | 修复后 M2 | 线上归一化（现） |
|---|---|---|---|---|
| 1 | **Feliks Zemdegs** | 127.58 | **42.46** | 58.70 |
| 2 | **Max Park** | 49.82 | **25.18** | 22.92 |
| 3 | Tymon Kolasiński | 72.00 | 22.02 | 33.13 |
| 4 | Seung Hyuk Nahm | 61.78 | 17.96 | 28.43 |
| 5 | Mats Valk | 62.48 | 13.48 | 28.75 |
| 6 | Kevin Hays | 33.88 | 12.04 | 15.59 |
| — | Bence Barát（现第 1，m2 = 100） | **217.34** | **7.90** | **100.00** |

**最关键的一处**：现行第一名 Bence Barát 的 217 分里，404 个被标为 CC 的领奖台中有 **395 个其实是匈牙利国家锦标赛**。
他从未拿过世界冠军，却在「世界 / 洲际领奖台」这一项上满分 100，Feliks 只有 58.7。

修复后 Bence 降到 7.90（跌出前 12），Feliks 成为 M2 第一。

**M2 总量**：14,807.1 → **1,236.22**（降至 8.35%）。
归一化分母 `modMax.m2` 要整体重标定，否则 0–100 区间会全部挤在底部。

## 4 两个已被排除的方向

### 4.1 决赛人数（field）不是主因

担心「场上只有 3 个人，前三名等于保底」。实测：

| 赛级 | 领奖台 | 决赛 ≤5 人 | 占比 | 平均决赛人数 |
|---|---|---|---|---|
| WC | 574 | 46 | 8.01% | 28.31 |
| CC | 1,825 | 99 | 5.42% | 18.73 |
| NC | 32,146 | 2,976 | 9.26% | 14.59 |

全站 ≤5 人决赛 **9.03%**，≤3 人 **2.81%**。
按 `min(1, (field/16)^0.35)` 加权后，M2 总量只降 **5.61%**，前 10 名次**一个都没变**。

**结论**：field 修正不是当前的主要矛盾，可以不做（或留作可选）。

### 4.2 名次权重 1 / 0.6 / 0.4 的取值

无实证依据，但影响面有限：改成 1 / 0.5 / 0.25 只改变同级内的相对关系，
不会改变「谁有资格进 M2」这个更根本的问题。**优先级低于赛级修复。**

---

## 5 三个真正待定的问题

### 5.1 要不要乘项目权重 `w_e`？

现在 6×6 世界冠军 = 3×3 世界冠军 = 1.0。

| | 只修赛级 | 修赛级 + 乘 `w_e` |
|---|---|---|
| Feliks | 42.46 | **25.58** |
| Max Park | 25.18 | **14.76** |
| Tymon | 22.02 | 13.20 |
| M2 总量 | 1,236.22 | 638.27（降至 51.63%） |
| 前三名 | 不变 | **不变** |

乘 `w_e` 后总量腰斩但前三不变，说明 **Feliks / Max / Tymon 的优势是结构性的**（他们在高权重项目上也拿冠军），
不是靠冷门项目堆出来的。这与 M1 的结论一致。

### 5.2 要不要加时代折算 `f_L`？

2005 年世界锦标赛 3×3 的参赛规模与 2025 年差一个数量级，现在完全不加权。
若与 M1 对齐乘 `f_L`，早期冠军会被折价（Feliks 的 26 个 WC 领奖台里多数在 2011–2019）。
**这条要单独实现，成本比 5.1 高**（需要按赛级 + 属地建时代池）。

### 5.3 「参加得多」是否应该线性累加？

M2 是纯求和。世界锦标赛两年一届，一个选手生涯最多参加约 10 届、每届最多 7 个项目；
洲际赛每年一次、机会约为 WC 的 3 倍。当前 Feliks 的 36 个 CC 领奖台贡献了 M2 的一半以上。

可选做法（任一）：
- **不处理**：机会差异是事实，参赛多本身就是能力
- **按项目取最优**：每个项目只算最好的一次领奖台（防「同一项目反复上台」）
- **按届去重**：每届世界 / 洲际赛最多计 N 个领奖台

## 6 修复代价

| 项 | 说明 |
|---|---|
| 代码 | `etl/build.js:294` 改 3 行，把 `else` 拆成「洲际 / 国家 / 其他」三支 |
| 数据 | **必须重跑 ETL**（约 100 秒），`js/data.js` 会重新生成 |
| 连带 | M3 会吸收 32,146 个领奖台，总量从 84,316 涨到约 92,900 |
| 归一化 | `modMax.m2` 与 `modMax.m3` 都要重标定，前端 0–100 显示会整体变化 |
| 前端 | 无需改代码，但个人页「M2 计算过程」的赛级标签会变（NZ Championships 会显示为国家级） |
