## 0 一句话说清 M4 是什么

**M4 = 一个人在历史上「被世界前排认可」的总时长**，按名次加权、按时代折算。

它和 M4 的最大区别是**时间维度**：M1 是「纪录阶梯上的持有段」，M4 是「按 PB 还原出的世界排名席位段」。

---

## 1 计分公式（唯一权威）

```
M4 = Σ_{e,t} w_e · Σ_段 (段长 / 365) · g(名次) · f(年代)

  e,t   = 项目 × 轨道（single / average），共 40 组
  w_e   = EV_WEIGHT_V2（三阶 1.0000 全站最高）
  g(r)  = r^-1.0        （名次 1..10，λ = LAMBDA_MAIN）
  f(y)  = ln(1 + N(y)) / ln(1 + N(baseYear))
          N(y) = 截至 y 年累计注册人数；baseYear = 全站最后首次参赛年
          ★ 与 M1-F1 **同源同口径**（M1.makeScopePool 全局池）
  段长  = 该选手连续占住前十席位的真实天数（**前十名单换人**才切段）
```

**方案 F（用户 2026-10-25 拍板采纳）**
```
某项目某年「零人参赛」 → 该年该项目的全部席位天 **不计分**
```
- 判定为**项目级**（该项目该年有 ≥1 人出过正式成绩 = 有竞争），单次/平均两条轨道共用
- 实现在**仿真层**（`closeSeg()` 跳过空窗年整段）→ `raw / eraG / eraE` / 各 λ / 名次拆解 / 全站名次表 **同步生效**，无口径分叉
- 命中：**4 个项目 / 23 个年份** —— `333` 1983–2002（20 年）、`pyram` 2004、`444bf` 2005、`555bf` 2005

## 8 已知边界（不修，但别当 bug 再报）

1. **重建 ≠ 官方历史排名**：官方从未公布过历史排名序列，本维度用「按 PB 还原」的口径。末位**值阶梯**与官方快照全部吻合（§4.5）说明还原正确，但**中间年份无法与官方对照**。
2. **并列成绩的裁定**：官方对同成绩使用同名次、组内顺序无语义；本模型采用「先达成者居前」的确定性规则，故并列密集的项目（最少步等）名单重合率略低，但**分值阶梯完全一致**。
3. **同一场比赛的排名变更会被记为一次换位**：PB 只在比赛结束日更新，榜单在该日整体刷新。
4. **多盲的解码依赖 WCA 的 `diff = solved - missed` 排序键**；官方存的是编码值，无法直接对表，故多盲组合不参与「值阶梯」校验。
5. **停办项目封口在 `EV_RETIRED_DAY`**：`closeSeg()` 传入 `capDay = min(停办日, 快照日)`，末段不再延伸到快照日。
6. **「组·年」量纲**：前十席位(年) 是跨 40 个组合的**求和**，不是自然年。
7. **方案 F 的判定是「项目级」而非「轨道级」**：某年该项目有人参赛、但某条轨道（如平均）无人出成绩时，那条轨道该年的席位仍会被计入。
8. **方案 F 只处理「绝对空窗」**：当年 3 人、4 人参赛这类「弱竞争」不在处理范围内。
9. **WCA 口径的限制**：1983–2002 年 WCA 之外确有大量魔方比赛，只是不在数据里。方案 F 按 WCA 口径判定为「空窗」；这正是设计意图 —— M4 的分值只应在**有可比数据**时产生。
10. **`Array.sort()` 是原地排序**：`top10Players.sort()` 会把同引用的 `ranked` 重排，导致名次表错位。**凡要「另存一版排序」一律 `[...arr].sort()`**。
11. **TSV 列位**：JS `split('\t')` 的 `c[0]` 对应 awk 的 `$1`；用 awk 写正则校验时要差一位。
