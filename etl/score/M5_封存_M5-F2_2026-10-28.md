## 0 一句话

**M5 = Σ_{e,t} w_e · rank^-1.0，没有任何时间项。**

旧口径用「参赛新鲜度 × PB 新鲜度」两层衰减去压制终身榜里的僵尸名次；
M5-F2 认为这套装置**贵而钝**（详见 §2），直接砍掉。
M5 从此诚实承认：它读的就是 WCA 的**终身 PB 榜**，答的是「你此刻**持有**着第几名」。
「守了多久」由 M1 表达，「压了对手多久」由 M4 表达 —— **M5 不再重复表达时间**。

## 1 计分公式（唯一权威）

```
M5 = Σ_{e,t} w_e · g(rank_{e,t})

  e,t      = 项目 × 轨道（single / average），共 33 个有数据的组合参与计分
  w_e      = EV_WEIGHT_V2（三阶 1.0000 全站最高）
  g(r)     = r^-1.0        （第 1 名 = 1.0，第 10 名 = 0.1）
  rank     = 官方 world_rank（WCA 终身 PB 榜）
```

**已删除的项**（M5-F1 的所有遗产）：
`decay(gapR)`、`decay(gapP)`、`DECAY_YEARS=5`、`DECAY_FLOOR=0.2`、`DECAY_MODE='dual'`。

> `gapR` / `gapP` **仍随明细输出**（`M5_by_event.tsv` 的 `gapR_years` / `gapP_years` 列），
> 用于人工识别僵尸条目，**但不进公式**。这是刻意的：保留可观测性，不保留影响力。

**未改的部分**（与 M5-F1 一致）：
深度 100、γ=1.0、双轨各 1.0、停办项目整体不计分、`EV_WEIGHT_V2` 同源、`SKIP_RETIRED`。

## 6 解封条件

**允许改动**（仅限三类）：数据更新后重跑、`SNAPSHOT` 同步、用户明确要求改口径。

**不允许的改动**：

- 把 `DECAY_MODE` 从 `'none'` 改回 `'dual'` / `'retire'` / `'pb'` ——
  这是本次变更的核心结论（§2），回退等于把已验证「贵而钝」的旋钮装回来
- 重新引入任何时间项（乘性折扣、加性惩罚、分段阶梯）而不走一次新的对照实证
- 改 `DEPTH` / `GAMMA` / `TRACK_WEIGHT` / `SKIP_RETIRED` / `EV_WEIGHT_V2`（沿用 M5-F1 的冻结约定）
- 把 `p.esum`（同源指标）与 M5 同时计入总分 —— 现势名次会被算两遍（M5-F1 D9 结论仍然有效）
- 自行删除 `gapR` / `gapP` 展示列 —— 僵尸条目失去可观测性，长尾就没人能发现

**回归验证**：重跑后须复现 1,257 人 / 95.8852；Top25 名单与 §4.2 逐位一致；
Feliks #59、Max #3、Stanley Chapel #6。

## 7 ✅ 下游已同步（2026-10-28 完成）

### 7.1 ⚠ 隐藏依赖：`sixdim.js` 根本不读 `M5_seats.tsv`

这是本次差点翻车的地方，务必记住：

```
M5_facts.tsv  ← sixdim.js 的**唯一** M5 输入（sixdim.js:155）
     ↑
m5_facts.js   ← 独立脚本，**曾经把双衰减硬编码在行 153-155**，不读主脚本的 CFG
```

`sixdim.js` 对 `M5_seats.tsv` / `M5_by_event.tsv` **一行都不读**。所以只重跑 sixdim/build
只会把旧口径再推一遍，且**不会报任何错**（静默失败）。

**修复**：给 `m5_facts.js` 加 `CFG_DECAY_MODE`（默认 `'none'`，保留 retire/pb/dual 对照档），
公式改为 `score = w_e · rank^-1 · dec`，与主脚本 `decCombo()` 同参同式。

⚠ `M5_facts.tsv` 与主脚本产物**不是同一个东西**：它是 **1982–2026 逐年年末快照**
（`years` 循环，供 `--asof` 历史查询），而主脚本只产出**单一当前快照**。不能互相替换文件。

## 8 已知边界（不修，但别当 bug 再报）

1. **僵尸名次全额计分** —— 这是 A 方案的定义性代价，不是缺陷。典型：
   Stanley Chapel 的 `555bf|average` #1（PB 6.83 年前）、林恺俊的 `333mbf` #63（PB 10.55 年前）、
   Sameer Aggarwal 的 `222|single` #18（PB 7.45 年前）。
2. **官方 ranks 是终身榜** —— M5-F2 直接承认这一点，不再近似修正。
3. **`fto` 无官方排名数据**；`333mbf` / `333mbo` 无 average 轨。
4. **并列名次按官方同名次处理** —— 40 组合里仅 `333fm|single` 有 4 人并列 #1。
5. **窗口口径（`RANK_MODE='window'`）保留但没有的双衰减** —— 该档位下 `WINDOW_DECAY` 仍可用，
   仅作对照，不作主口径（D2 的语义脱钩 / 深度截断失效问题依旧）。
6. **PB 达成日仍被计算**（38,362 条），虽然不再进公式 —— 为的是保住 `gapP` 展示列与对照实验能力。
   若日后要提速，可在 `none` 模式下跳过 PB 扫描（约省几秒），但会丢列。
