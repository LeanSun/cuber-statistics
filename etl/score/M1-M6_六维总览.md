## 2. 逐维详解

### M1 纪录持有 ✅已封存 M1-F2（取代 M1-F1，2026-10-25）

> F1 → F2 的解封原因：M6-F2（突破幅度）与 F1 的 r 分量是**同一个数学**（`ln(前值/现值)`），
> 双计实证 ρ=0.734 → r 剥离归 M6，M1 变**纯持有版**。F1 公式与基线（Max 83.7131）仅历史存档。

**计分公式（唯一权威）**
```
score = Σ_段 [ min(T, 30年)/365 × V_L × ρ_s × f_L × w_e ]      （r ≡ 1，G_ref 移除）

T    = 持有天数
V_L  = 级别价值 (WR/CR/NR)
ρ_s  = 该级别该属地的竞争密度
f_L  = 该持有区间内的时代折算均值
w_e  = 项目权重
```

**关键常量与定案**
- `w_e = 0.30 + 0.70 × s_e^0.75`（`s_e = pr_e × √ar_e`），**三阶 `s≡1 → w≡1.0000` 结构性保证**
- 停办项目末段必须封口：333ft→2020-01-01、magic/mmagic→2013-01-01、333mbo→2009-02-01
- `f_L` 时代折算**保留**（corr(f, ln 段长)=0.0242，不存在「段长被罚两次」）
- ★ F2 副作用（改善）：F1 的「阶梯首段 r=0」边界**消失** —— Minh Thai 守 21.2 年终于得分
  （2,696 个首段重得 19.36 分）；F1 记录的「基准漂移」问题随口径更换自然关闭

**回归基准（M1-F2）**：Max **40.8579** / Feliks **35.9980** / 结构四项不变
（records 55,244 / 阶梯 4,822 / 段 25,270 / 有分 4,952）/ `test_runs.js` 16 项全绿
**实现**：`m1_hold.js`（生产）+ `score_record.js`（F1 存档）；事实表 `M1_facts.tsv` / `M1_hold_full.tsv`

### M2 领奖台 ✅已封存 M2-F1 / M2-F1-r1

**一句话**：一个人的「生涯荣誉总量」= 锦标赛领奖台 + 普通赛领奖台，**两条维度总量各占一半**。

```
总分 = Σ[ base × decay × (OP? β : 1) ]

base  = P × K × (hill(F)/hill(REF_年代本地))^γ × f_pool × w_e
decay = OP ? n^-α : 1
β     = S2/S3 反解，使 M2/M3 总量各半
```

**关键定案**

### M4 统治力 ⚠️口径已跑通并验证（用户 2026-10-25 定为「保持在 WR10 有多久」）

**用户最终定义**：**统治力 = 选手保持在世界前十（WR10）有多久**（在两个候选口径中选了「历史占席积分」并把席位深度定在**前十**）。

**核心工程突破**：WCA v2 导出的 `ranks_single` / `ranks_average` **只有现势快照**，没有历史排名序列。
必须从 `results.tsv` 重建：`某时刻的世界排名 = 所有人「截至该时刻的 PB」排序`。

```
对每个 (项目 e, 轨道 t ∈ {single, average})：
  ① 全部成绩按时间排序（计数排序 O(n)）
  ② 只保留 PB 进步时刻
  ③ 维护长度 ≤10 的世界前十名单，随时间演进
  ④ 名单变化时切分时间段

d10(e,t)  = 占住前十席位的总天数
d1(e,t)   = 坐在第一的总天数
seat(e,t) = Σ_段 段长 × g(名次)      g(r) = r^-λ

M4_raw = Σ_{e,t} w_e · seat(e,t) / 365
M4_era = Σ_{e,t} w_e · Σ_段 (段长/365) · g(名次) · f(年代)
```

### M5 当前排名 ✅已封存 M5-F1，未接入

**你定义的**：对比选手当前的世界排名；如果选手没有参加比赛则默认退役，排名就考虑到不参赛的第 5 年。

**系统现状（旧）**：`build.js:797`
```js
const m5 = (evCount / 21) * 0.7 + Math.min(evCount / 17, 1) * 0.3;
```
这是**跨项目广度**，与「当前世界排名」无关。新 M5 是独立实现，不复用它。

**⚠️ 关键事实（决定了 M5 的整个设计）**：WCA 的 `ranks_single.tsv` / `ranks_average.tsv`
**不是「当前排名」，而是「按 PB 排序的终身榜」** —— 退役 10 年的人只要 PB 没被超越，2026 年仍显示第 5 名。
实测 `333mbo` 单次 #1 已 7.5 年没参赛、`magic` 单次 #1 已 10.9 年、`mmagic` 单次 #3 已 18.7 年；
而 `333` 单次 Top5 全部 0.0–0.1 年内参赛。**活跃项目的榜是「当下」的，停办项目的榜是「化石」的。**

**定稿口径（M5-F1）**
```
M5 = Σ_{e,t} w_e · rank_{e,t}^-1.0 · max(0.2, 1 - gapR/5 × 0.8) · max(0.2, 1 - gapP/5 × 0.8)

  w_e   = EV_WEIGHT_V2（三阶 1.0000）
  深度   = 世界前 100（超出 0 分）
  轨道   = single / average 双轨各计一次（权重各 1.0）
  停办项目 = 整体不计分（magic/mmagic/333mbo/333ft）
  gapR  = 该项目内末次参赛距今天数（★ 按项目内，不按选手全局）—— 参赛新鲜度
  gapP  = 该项目该轨道 PB 达成距今天数                          —— 名次新鲜度
```

**★ 两层衰减是 M5-F1 的核心修正（P1 病灶）**

只做「参赛新鲜度」时，衰减**只惩罚完全不参赛的人**，**完全不惩罚「还在参赛、但名次是几年前刷出来的僵尸名次」**：

|---|---:|---:|

| **衰减完全失效（活跃但 PB 已≥2y 未刷新）** | **617** | **15.9%** |

加一层 `decay(gapP)` 后（定稿 F3）：
