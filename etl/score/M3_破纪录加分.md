## 1 设计口径

- **适用范围**：仅锦标赛 —— 世锦赛(WC) / 洲锦赛(CC) / 国锦赛(NC)。普通赛(OP)不计。
- **纪录级别**：世界纪录(WR) + 洲纪录(CR) + 国家纪录(NR) 三级都计分。
- **单条加分** = `W_REC[级别] × W_TIER[赛事级别]`
  - `W_REC = { WR:1.0, CR:0.4, NR:0.15 }`，镜像 M1 的级别价值常量，保持口径一致
  - `W_TIER = { WC:1.0, CC:0.6, NC:0.4 }`，世锦赛破纪录最重、国锦赛最轻
- **单次(single)与平均(average)各计一次**；同一比赛同项目同类型多轮次只计一次（去重）。
- **不做时代折算**：每一条破纪录成就等权（时代因子作为可调旋钮，默认关）。
- **不受 S5 属地门槛约束**：WR/CR/NR 是客观成就，客场破纪录照样计。

## 5 影响与说明

- **M3 是独立计分维度，不并入 M2 内核。** 本脚本独立扫描 results.tsv 的纪录标记列产出 M3 分；
  第 3 节的组合榜（M2 融合分 + M3 独立加分）即「M2 + M3」总榜预览，基于 M2 全量排名重排，边界已自检。
- 破纪录加分**不改变 M2 的头部格局**（Feliks / Max / Tymon 仍居前三），主要抬升「在大赛上破过纪录」的选手；
  头部三强之间的差距会被放大（Feliks 因锦标赛破的 WR 最多，受益最大）。
- 权重 `W_REC` / `W_TIER` 与「是否引入时代折算」均为可调旋钮，看效果可再微调。
