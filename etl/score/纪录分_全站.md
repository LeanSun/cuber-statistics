## 0 计分结构

```
score = Σ_段 [ r × min(T,30年)/365 × V_L × ρ_s × f_L × w_e ]
  r   = min(G / G_ref(e,轨,级别), 3)   ← 按级别归一
  G   = ln(前一位留下的值 / 本段最好值)
  T   = 本人持有到被别人打破的天数
  V_L = WR 1.0000 / CR 0.4000 / NR 0.1500
  ρ_s = 该级别该属地的竞争密度
  f_L = 该区间的时代折算均值   ← 2026-10-24 决定保留，见第 6 节
  w_e = 项目权重（EV_STAT 全量重算）
```

> **为什么 G_ref 按级别分**：级别价值已由 `V_L` 承担，若三者共用一个 `G_ref`，
> 小国 NR 天然跨度大（常 2–5 倍），会把 `G_ref` 抬到世界纪录的 3 倍，
> 反过来把 WR 段的 `r` 压到 0.3 以下。按级别分后，每个级别内部 Σr = 段数，跨项目可比。

## 6 时代折算：为什么保留

**决定：保留 `f_L`。** 这一节记录决定依据，以及它已知的代价，避免以后被当成疏漏重新讨论。

### 6.2 「双重计入」的实测：几乎不存在

原先的担心是：占有段奖励守得久，早期竞争少所以段天然长，`f` 再扣一次等于罚两遍。
实测否掉了这个担心，而且方向和我预期相反 —— **越晚的段反而越长**：

| 年代 | 平均守（天） | 说明 |
|---|---|---|
| 2000–2004 | 838.9747 |  |
| 2005–2009 | 675.5482 |  |
| 2010–2014 | 765.3096 |  |
| 2015–2019 | 934.7727 | 本表最长 |
| 2020–2024 | 632.8098 |  |
| 2025–2029 | 259.2543 | 段多但都短（近期纪录仍在延续） |

全站 25,270 段的相关性：`corr(f, ln 段长) = 0.0241`、`corr(f, 段长) = 0.0156`。
两者都接近 0，说明 `f` 与段长**几乎不相关**，不存在「同一件事被罚两次」。

原因有两条，都是结构性的：

1. `f` 按**整个持有区间取均值**，不是按起始年取单值。一条 2012→2018 的段，后半段已经按接近 1.0 计。
2. 早期段普遍**更短**。2005–2009 年平均 676 天，2015–2019 年平均 935 天 ——
   早期玩的人少但纪录也更粗糙，换手比想象中快；反而是 Max Park 这类现代统治者的段长达 2000–3200 天。

所以 `f` 扣的**不是**段长带来的红利，而是「当时的参赛人口」。这正是它该做的事。

### 6.3 保留的三个理由

1. **跨时代可比性**。魔方人口从 2003 年的几百人涨到 2026 年的三十万，同一个「世界第一」
   在 2005 年和 2025 年的稀缺程度差两个数量级。不折算等于说 2005 年的 WR 和 2025 年的 WR 一样难。
2. **防早期红利**。若取消 `f`，早期选手会同时吃到「竞争少」和「不折价」两份好处，天平反而更歪。
3. **可解释**。`f` 只依赖「年代 + 属地」，不依赖选手个人表现，任何人都能独立复算。

### 6.4 保留它的代价（已知并接受）

| 代价 | 实测 | 说明 |
|---|---|---|
| 早期选手被压低 | Feliks Zemdegs 平均 f 0.7450 vs Max Park 0.9361 | 差值 1.2566×，直接决定了名次 |
| 名次对折算敏感 | 不折算 1.0008×（打平），折算 0.8597× | 这是本口径最大的不确定来源 |

> 敏感性已量化：去掉 `f`，两人从 0.8597× 变成 1.0008×，从「一强一弱」变成「实质打平」。

**结论：保留。** 若将来要削弱，正确做法是收窄 `f` 的动态范围（例如 `f^0.5`），而不是删除 ——
删除会让「跨时代可比」这个前提整个消失，收窄只调整权重。

### 6.5 另一个边界：阶梯首段记 0 分

第 6.1 表里 1980–1984 那 19 段平均 0 分，原因不是折算，而是**首段没有前值可比**：

- `G = ln(前一位留下的值 / 本段最好值)`，阶梯第一段没有「前一位」，`G = 0` → `r = 0` → 整段归零。
- 这种情况共 **2,696 段（占 10.7%）**，其中 WR 层 28 段。
- 最典型的是**历史上第一条三阶 WR**：1982-06-05 Minh Thai 22.95 秒，守了 **7,749 天（21.2 年）**，得 0 分。

这不是 bug，是定义边界：没有前值就测不出「推深多少」。但它确实让「守了 21 年」这件事完全不计分。

| 方案 | 做法 | 对两人的影响 |
|---|---|---|
| 现状（默认，`FIRST_R=0`） | 首段 r=0，不计分 | 71.2782 / 83.7131 |
| 中性强度（`FIRST_R=1`） | 首段 r=1（相当于「一次典型推深」） | 71.3909（+0.1127）/ 83.9201（+0.2070） |

中性强度方案只抬高 `r=0` 的首段，对这两人的增量相当于自身分数的 0.16% / 0.25%，**名次不变**。
开关：`FIRST_R=1 node etl/score/score_record.js`。默认关闭，等口径确认后再定。
