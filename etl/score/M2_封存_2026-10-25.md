## 0 一句话说清 M2 是什么

**M2 = 一个人的「生涯荣誉总量」= 锦标赛领奖台（旧称 M2）+ 普通赛领奖台（旧称 M3），两条维度在总量上各占一半；每条的单价由「赛事深度 × 时代折算 × 项目权重 × 赛级系数」共同决定，普通赛额外按重复次数衰减。**
> 注：此处「M3（普通赛）」是融合内核内部的历史命名，**与后来独立的「M3 破纪录加分」维度无关**——后者由 `m3_record_bonus.js` 独立计算，见 §6 文档清单。

## 1 计分公式（唯一权威）

```
总分 = Σ_该选手所有条目 [ 单条贡献 ]

单条贡献 = base × decay × (赛级 == OP ? β : 1)

base = P(pos) × K_tier × ( hill(F) / hill(REF_ev,同时代) )^γ × f_pool × w_e

  P(pos)            = 金 1.0000 / 银 0.6000 / 铜 0.4000
  K_tier           = { OP:1.0, NC:1.0, CC:1.6, WC:1.6 } × (guest ? 0.5 : 1)
  hill(N)          = NSAT × ln(1 + N/NSAT)，NSAT = 500
  REF_ev,同时代    = 该项目同时代普通赛到场人数中位（±2/3/5/8/15 年滚动窗，
                     样本 ≥20 取最紧窗；附近无任何普通赛则退回全局 REF）
  f_pool           = F_POOL[tier] 查表 → 'WR' 取全局池 f、'NR' 取举办国池 f
  w_e              = EV_WEIGHT_V2（见 M1-F1 §2.2；三阶 1.0000 全站最高）

  decay            = 赛级 == OP ? n^-α : 1
                     （n = 同人同项目第 n 次普通赛领奖台，按时间序；锦标赛不衰减）

β = S2 / S3              # 总量等分：M2 与 M3 各占总分 50%
  S2 = Σ_{tier∈{NC,CC,WC}} base × decay
  S3 = Σ_{tier == OP}      base × decay
```

**β 的语义**：因为 M2（头部厚、长尾空，93.1% 的人为 0）与 M3（头部薄、长尾厚）形状不同，不可能同时让「总量各半」和「榜首同分」成立。取 **总量等分** —— 先保证两个维度在总量上平起平坐（见 §4 论证）。β 不是旋钮，是数据反解出的常数。

## 4 论证与已知边界（不修，但不要再当 bug 报）

### 4.1 为什么 β 取「总量等分」而非「榜首同分」
要让纯 M2 第一名 = 纯 M3 第一名，β 需取 **1.4069**，此时普通赛总量会占到 **86.26%**、M2 被压成零头 —— 不可接受。故取总量等分（β=0.2241），融合后 M2/M3 各占 50%。

### 4.2 greater_china 赛事的归属
`ChinaChampionship` 等 `championship_type = greater_china` 的赛事，host 在亚洲 → 亚洲选手计本洲 CC，其余按客场折半（如 Feliks 的中锦赛）。此口径已落地并验证。

### 4.3 洲际机会不均 —— 维持现状（用户拍板）
欧洲全史办过 12 届洲锦赛、大洋洲仅 4 届；Feliks 本洲 CC 仅 14.7 分（参加 1 届），Tymon 82.6 分（参加 3 届）。差异一半来自地理运气，用户决定保留（不封顶、不衰减）。

### 4.4 NC 维持举办国池（未改全球/洲池）
国锦赛本质是国家赛事，用举办国 NR 曲线更合理；若日后想改，只需切 `F_POOL`。

### 4.5 REF 退回全局的边界
某 (项目, 年份) 附近 ±15 年内无任何普通赛时，`REF_ev,同时代` 退回全局 REF。属定义边界，非实现错误。
