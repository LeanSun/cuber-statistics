# M4 · 统治力 · 世界排名席位时间积分

> 生成时间：2026-10-25 15:00:11
> 数据：WCA 导出 v2.0.2 / v288，快照日 2026-10-15｜脚本 `etl/score/m4_dominance.js`
> **独立维度**，不并入 M1（持有纪录价值）/ M2（融合领奖台）/ M3（破纪录加分）内核。

## 0 一句话

**M4 = 「在世界的牌桌上坐了多久」**：把每个项目的世界排名还原成时间线，
统计每位选手**占住世界前十席位（WR10）多少天**、其中**坐第一多少天**。

与其它维度的分工：

| 维度 | 问的问题 |
|---|---|
| M1 | 纪录**守**了多久（持有价值） |
| M2 | 领奖台拿了多少（荣誉总量） |
| M3 | 在大赛上**推破**纪录多少次（突破动作） |
| **M4** | **在世界前十/第一的位置上坐了多久（统治力）** |

## 1 口径

### 1.1 为什么必须重建历史排名

WCA v2 导出的 `ranks_single` / `ranks_average` **只有导出当天的快照**，没有历史序列。
因此「保持了多久」只能从 `results.tsv` 重建：

```
某时刻的世界排名 = 所有人「截至该时刻的最好成绩（PB）」排序
```

这与官方口径一致（官方 best 列就是选手历史最好成绩），重建结果在 §3 与官方快照逐项对表。

### 1.2 公式

```
对每个 (项目 e, 轨道 t ∈ {single, average})：
  ① 全部成绩按时间排序（计数排序 O(n)）
  ② 只保留「个人最好成绩」的进步时刻
  ③ 维护长度 ≤10 的世界前十名单，随时间演进
  ④ 名单变化时切分时间段
  ⑤ 【方案 F】逐年检查：当年该项目零人参赛 → 该年整段跳过，不计任何席位

  d10(e,t)  = 该选手占住前十席位的总天数（不含空窗年）
  d1(e,t)   = 该选手坐在第一的总天数（不含空窗年）
  seat(e,t) = Σ_段 段长 × g(名次)      g(r) = r^-λ

M4_raw = Σ_{e,t} w_e · seat(e,t) / 365
M4_era = Σ_{e,t} w_e · Σ_段 (段长/365) · g(名次) · f(年代)

  w_e = EV_WEIGHT_V2（三阶 1.0000 全站最高）
  f   = M1-F1 同源全局时代系数 ln(1+N(y))/ln(1+N(base))

  ★ 方案 F 不是「打折」，是「取消计分资格」：
    当年该项目零人参赛 → 那一年根本没有竞争 → 那一年的世界排名无意义
    → 该年席位天数为 0（对 raw / era / 各 λ 同步生效）
```

### 1.3 边界处理

| 项 | 处理 |
|---|---|
| DNF(-1) / DNS(-2) / 无成绩(0) | 剔除 |
| 取消的赛事（cancelled=1） | 不计入 |
| 停办项目 333ft/magic/mmagic/333mbo | 时间线封在停办日（EV_RETIRED_DAY） |
| **空窗年（当年该项目零人参赛）** | **该年席位不计分（方案 F，见 §4.9）** |
| 多盲 multi 编码值 | 先解码成可比成本再排序 |
| 同值并列 | 在位者保留席位（挑战者需严格更快才挤入） |

### 4.7 停办项目的封口：持续时间只算到项目停办的那一刻

**规则**：项目被停办后，它的历史席位**只保留到停办日**，`停办日 → 快照日` 这段时间
不再产生任何席位。理由很直白——项目已经死了，没有人能再打破纪录，
「守着一条没人能破的记录」不是统治力。

| 项目 | 停办日 | 停办后到快照日 | 单组合最长前十占位 | 末段终点 | 封口 |
|---|---|---|---|---|---|
| 旧多盲 `333mbo` | 2009-02-01 | 6465 天（17.7 年）| 797 天 | 2009-02-01 | ✓ 止于停办日 |
| 脚拧 `333ft` | 2020-01-01 | 2479 天（6.8 年）| 3486 天 | 2020-01-01 | ✓ 止于停办日 |
| 十二板 `mmagic` | 2013-01-01 | 5035 天（13.8 年）| 2354 天 | 2013-01-01 | ✓ 止于停办日 |
| 八板 `magic` | 2013-01-01 | 5035 天（13.8 年）| 1515 天 | 2013-01-01 | ✓ 止于停办日 |

> **校验方式**：看**末段的终点**是否 ≤ 停办日（而不是看总占位天数）。
> 某组合的总占位可以很长（那是停办前真实占着的），但**最后一段必须停在停办日**，
> 不能再延伸到快照日。

> **末段封口的实现**：`simulateSorted` 的收尾 `closeSeg()` 传入 `capDay = min(停办日, 快照日)`，
> 而不是固定用快照日。这与 M1-F1 的 `EV_RETIRED_DAY` 是同一套封口逻辑。

### 6.3 为什么时代折算仍然是必须的（Minh Thai 案例）

**Minh Thai** 于 1982-06-05 写下第一条三阶世界纪录（22.95 秒），这条纪录一直挂到 2003 年 WCA 成立，
**独占世界第一名 21.2 年**。

> 方案 F 已经把这段「无竞争的静止期」整段剔除（见 §4.8 / §4.9）。
> 但**时代折算仍然不能省** —— 因为 1982 年那 210 天是**有竞争的**（19 人同场），
> 它该拿多少分，取决于「当年全世界有多少人在玩魔方」。

| 口径 | Minh Thai 分 | M4 排名 |
|---|---|---|
| 无时代折算（含方案 F） | 1.2192 | #222 |
| **M1 全局池 ln 折算 + 方案 F（定稿）** | **0.3266** | **#461** |
| 项目级池 ln 折算 + 方案 F | 0.3745 | #411 |

1982 年全世界登记在册的魔方选手只有几十人 —— 当时的「世界第一」与 2026 年的「世界第一」
不是同一件事。时代折算就是把这一层差异折进分值。

**两条修正是正交的，各自管一件事**：

| 机制 | 管什么 | 回答的问题 |
|---|---|---|
| 方案 F（空窗年归零） | **有没有竞争** | 当年这个项目有人参赛吗？ |
| 时代折算 f(y) | **竞争者有多少** | 当年整个魔方运动有多大？ |

只有折减「有多少人」而不处理「有没有人」，就会漏掉停滞期；
只有处理「有没有人」而不折减「有多少人」，就会把 1982 年当今天看待。

## 9 已知边界

1. **重建 ≠ 官方历史排名**：官方从未公布过历史排名序列，本维度用的是「按 PB 还原」的
   口径；末位**值阶梯**与官方快照全部吻合（§3）说明还原正确，但中间年份无法与官方对照。
2. **并列成绩的裁定**：官方对同成绩使用同名次、组内顺序无语义；本模型采用「先达成者居前」
   的确定性规则，故并列密集的项目（最少步等）名单重合率略低，但**分值阶梯完全一致**。
3. **同一场比赛的排名变更会被记为一次换位**：PB 只在比赛结束日更新，榜单在该日整体刷新。
4. **多盲的解码依赖 WCA 的 `diff = solved - missed` 排序键**；官方存的是编码值，
   无法直接对表，故多盲组合不参与「值阶梯」校验。
5. **停办项目封口在 EV_RETIRED_DAY**：`simulateSorted` 收尾的 `closeSeg()` 传入
   `capDay = min(停办日, 快照日)`，末段不再延伸到快照日（详见 §4.7）。
   这是 M1-F1 的同一个坑，M4 在 2026-10-25 补上了封口。
6. **「组·年」量纲**：前十席位(年) 是跨 40 个组合的**求和**，不是自然年。
7. **方案 F 的判定是「项目级」而非「轨道级」**：以「该项目该年有 ≥1 人出过正式成绩」
   作为「有竞争」的判据，单次与平均两条轨道共用。
   已知不彻底处：某年该项目有人参赛、但某条轨道（如平均）无人出成绩时，
   那条轨道该年的席位仍会被计入。组合级差异见 §4.9 的统计。
8. **方案 F 只处理「绝对空窗」**：当年 3 人参赛、4 人参赛这类「弱竞争」不在处理范围内
   （那属于「密度门槛」方案 C 的范畴，未采纳）。
9. **WCA 口径的限制**：1983–2002 年 WCA 之外确有大量魔方比赛，只是不在数据里。
   方案 F 按 WCA 口径判定为「空窗」；若认为「无 WCA 记录 ≠ 无竞争」，
   则该规则会低估早期 —— 但这正是设计意图：M4 的分值只应在**有可比数据**时产生。

1. **「坐在第一」正是「统治力」本身**。剔除它等于把 M4 从

### 10.3 Q6：弱竞争（当年只有 3~10 人参赛）要不要折算

**问题**：方案 F 消掉了「当年 0 人参赛」。剩下「当年只有 3 个人参赛」
这种情况 —— 名次虽然是第一，但对手太少，含金量打折吗？

**实测**（密度门槛方案 C，`min(1, 当年参赛人数 / ref)`）：

| ref 阈值 | 全站合计 | Top10 与现状重合 | 受影响人数（变动 > 5%） |
|---|---:|---:|---:|
| 3 | 934.5194 | 10/10 | 1 |
| 5 | 934.1982 | 10/10 | 1 |
| 10 | 932.9950 | 10/10 | 5 |
| 20 | 929.6491 | 10/10 | 13 |
| 30 | 925.7941 | 10/10 | 20 |
| 50 | 919.9717 | 10/10 | 27 |

1. **对头部零影响**：ref 从 3 到 50，Top10 都是 10/10 不变，Top25 也 25/25 不变；
2. **阈值是拍脑袋的**：ref 取 10 还是 30，收益差 4 倍，没有客观依据；
3. **ref 调大反而误伤真实老将**：受损最大的是 Dror Vomberg（−26.8%）、
   Jeff Goetz（−20.4%）这类**在项目早期活跃过**的选手 ——
   他们当年确实只有几个人玩，但那是**项目的真实历史**，不是虚胖；
4. 方案 F 已经掐掉了最严重的一类（0 人参赛），剩下的属于长尾。

**M4 定稿公式**

```
M4 = Σ_{e,t} w_e · Σ_段 (段长/365) · g(名次) · f(年代)

  e,t   = 项目 × 轨道（single / average），共 40 组
  w_e   = EV_WEIGHT_V2（三阶 1.0000 全站最高）

  f(y)  = ln(1+N(y)) / ln(1+N(基准年))    N = 累计注册人数（M1-F1 同源）
  段长  = 该选手连续占住前十席位的真实天数（名单变化才切段）

  ★ 方案 F：Σ_段 只累加「当年该项目有人参赛」的年份；
    空窗年的天数直接不计（不是打折，是取消计分资格）
```

## 11 回顾：停滞期问题是怎么被方案 F 解决的
