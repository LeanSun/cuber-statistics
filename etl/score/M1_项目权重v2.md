## 1 旧表（`js/calc.js` 的 EVENTS[].w）错在哪

三件事，都能量化：

**① 量程不够。** 1.0000 → 0.5800，全区间只有 **1.7241 倍**。
   而真实差距：三阶人均参赛 NaN 次，四盲 31 次，差 **— 倍**。
   用 1.7241 倍的尺子量 — 倍的差距，尺子本身就不够长。

**② 分不开相近项目。** 四盲 0.8000 vs 三盲 0.8400，只差 5.00%。
   而两者的规模指数差 **8.1 倍**（0.091 vs 0.011）。
   一个只有 5% 差别的相邻档位，不可能承载 3 倍的真实差异 —— 它把两者压成了同一档。

**③ 没有来源。** 整张表没有任何计算过程，改一个值也无人能复核。
   它实际起的作用是"给每个项目一个体面的数字"，而不是"定价"。

## 2 新度量：项目规模指数 s_e

两个分量，都从 `evS` 直接可算：

```
pr_e = 该项目活跃人数 / 三阶活跃人数              ← 广度：多少人在玩
ar_e = 该项目人均参赛次数 / 三阶人均参赛次数        ← 深度：每人玩多久
s_e  = pr_e × sqrt(ar_e)
```

**为什么 ar 开根号**：人均次数是同一批人的重复投入，边际价值递减。
不开根号（即纯人次份额 pr×ar）会把六阶七阶压死：
六阶的活跃人数是三阶的 20%，只因为人均次数少（56 次 vs NaN 次），
人次份额只有 0.0282，落到三盲之下。这与「大阶 WR 是硬通货」的直觉相反。
开根号后六阶 s=0.074 → w=0.3996，
略低于三盲（0.4159）而明显高于四盲（0.3241），三者连成一条合理的斜线。

观测数据核对（同口径自校验）：`EV_STAT` 与现算的最大偏差 —— pr 0.0000（SQ1）、ar 0.0000（五阶）。
（表内保留 3 位小数，偏差上限 5×10⁻⁴，不影响任何排序。）

## 3 公式与三条结构保证

```
w_e = floor + (1 − floor) · s_e^γ
floor = 0.3000    γ = 0.7500    停办项目再 × 0.8500
```

三条保证，**只依赖公式形状，与数据无关**：

| 保证 | 为什么成立 |
|---|---|
| 三阶恒为最高 | `s_333 ≡ 1` ⇒ `w_333 = floor + (1−floor) = 1`，是上界 |
| 排序 ≡ 规模排序 | `s^γ` 在 `s>0` 上严格单调 ⇒ 不会出现「规模差 20 倍、权重差 5%」 |
| 冷门不清零 | 值域 `[floor, 1]`，最低也有 `0.3000` |

后两条是旧表缺的：旧表的排序并不严格对应任何可观测量，且相邻档位挤在一起。

**一处没有按原建议改**：评审里提过把 10 年硬截顶换成饱和函数 `T_eff = dsat(1−e^(−T/dsat))`，理由是"10 年等于没 cap"。
实测发现饱和函数会给**所有**长段打折（dsat=5 年时守 4 年只能算 2.7 年，−31%），这与「守 2000 天就得算 5.48 年，一分不少」直接冲突。
所以 v2 保持线性，只把 cap 从 10 年放到 **30 年**当数据边界（防 tEnd 缺失造出的伪长段）。饱和函数保留为可选参数 `dsat`，供敏感性分析。

## 8 边界与未决

1. **`pr` 的「活跃选手」门槛是选出来的，不是数据给定的。** 本文取「累计参赛 ≥ 3 场」（92,473 人，占全量 30.82%）。
   阈值从 ≥1 收到 ≥10，三阶对次高的领先从 37.19% 收窄到 13.97%（对照见 `EV_STAT_阈值扫描.md`）。
   取 ≥3 是为了剔除一次性参赛者；取 ≥10 会几乎退回旧表，区分度消失。
2. **`w_e` 仍然只到项目级，不分轨道。** 单次与平均用同一个 `w_e`；
   如果发现单次轨与平均轨的竞争密度差很多（例如多盲只有单次），需要拆成 `w_{e,t}`。
3. **`γ` 没有数据依据，是价值选择。** 本文给的是曲线与两端后果，不是"正确答案"。
4. **三阶领先 17.93% 是否够"明显"，由你定。** 这条只有一维旋钮，改 γ 即可，不必改结构。
