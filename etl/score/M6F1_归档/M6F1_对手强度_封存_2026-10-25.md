## 2 计分公式（唯一权威）

```
M6_i = Σ_r excess(r) × w(r)

  excess(r) = oppQ(r) − base(cell(r))

  oppQ(r)   = mean{ strength[o|event|year] : o 是同场领奖台的其他人（≠ r 的选手） }
  strength[pid|event|year] = 该选手在 (项目, 年代) 池内按「当年最好成绩」的名次分位
                              q = 1 − i/(n−1)，i=0 最强 → q=1.0
  base(cell) = median{ oppQ : 同 (项目, 年代, 赛级) 内所有领奖台记录 }
  cell(r)   = (r.event, r.year, r.tier)
  w(r)      = 冠军 1.0 / 亚军 0.6 / 季军 0.4
  tier      = WC 世锦赛 / CC 洲锦标赛 / OP 普通赛

  聚合**不乘任何 n^±α** —— 次数归 M2，M6 只管质量
  无对手可击败时 excess(r) = 0（不加分不扣分）
```

## 7 已知边界

1. **强度池只用单次成绩** —— average 轨的对手强度实际是用单次成绩衡量的。
2. **分位法把「同池内相对位置」当作强度** —— 池子极小时（如 1982 年三阶只有 19 人）分位不稳定。
3. **210 个基线 cell 的样本量 ≤ 3** —— 这些格的基线是弱估计（中位 87，最大 6,285）。
4. **对手池是「同场领奖台」** —— 若某场只有 1 人进决赛，无对手，excess 记 0。
5. **时代归一自建历史分位** —— 官方 `ranks_*.tsv` 是现势快照，不能用。
6. **负分占 73.5%** —— 进六维总分前**必须**做归一化（秩变换 / 分位数 / 加权合成）。
7. **全站总量为负**（−11,518.7578）—— 残差口径的必然结果，不代表模型出错。
