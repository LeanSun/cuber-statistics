# M6 对手强度 · 定稿报告（M6-F1）

> 生成脚本 `etl/score/m6_strength.js`｜数据快照 **2026-10-15**｜WCA 导出 **v2.0.2 / v288**
> 口径状态：**已定稿并封存**（2026-10-25）

## 0 一句话

**M6 = 你做成每一件事时，对面站的是多强的人。**

M1–M5 全在回答「**做了多少 / 做了多久 / 现在如何**」；
M6 回答「**这件事到底有多难**」。
一个人在小圈子里拿一百个冠军（M2 会记他），但每个对手都是当年该项目的普通选手 ——
M6 会给这个「一百」打上很低的分。

## 1 口径

### 1.1 五步

```
1) 实力池  strength[pid|event|year] = 该选手在 (项目, 年代) 池内的成绩分位
                ↑ 池 = 当年在该项目有成绩的所有人；分位越大越强

2) 对手池  oppQ(r) = 同场领奖台中「其他人」的分位均值
                ★ 对冠军/亚军/季军是对称的 —— 三人面对同一组人

3) 基线    base(cell) = 同 (项目, 年代, 赛级) 内所有领奖台记录 oppQ 的中位数
                cell = 「在这个赛级的这个项目里，通常能击败多强的对手」

4) 超额    excess(r) = oppQ(r) − base(cell(r))
                无对手可击败时记 0（无信息 ≠ 负贡献）

5) 聚合    M6_i = Σ_r excess(r) × w(r)     w = 冠军 1 / 亚军 0.6 / 季军 0.4
                ★ 不乘任何 n^±α —— 次数归 M2，M6 只管质量
```

### 1.2 成绩归一（三种 format 统一成「越小越强」）

| format | 项目 | 原始值含义 | 归一后 |
|---|---|---|---|
| `time` | 大部分项目 | 耗时（ms） | 直接用 |
| `number` | `333fm` 最少步 | 步数 | 直接用（**步数越少越强**） |
| `multi` | `333mbf` `333mbo` | 编码值 | `decodeMulti` → cost |

> ⚠️ `333fm` 与 multi 是旧实现里**两个方向性 bug**的来源，见 §2。

### 1.3 边界处理

| 项 | 处理 |
|---|---|
| `pos` 语义 | 只有 `round_type_id ∈ {f,c}` 的行，pos 才是最终名次（其余是轮次内卡位，最大 912） |
| 无对手可击败 | excess 记 0，不加分不扣分（**18,311 条**，4.19%） |
| 同场只有 1 人进决赛 | 同上，excess 记 0 |
| 基线 cell 样本量 | 中位 87，最小 1；≤3 的有 210 个（基线不稳，已记入诊断） |
| 停办项目 | 不排除 —— M6 衡量的是「历史对决质量」，与项目是否还活跃无关 |

### 2.1 对手池语义的修正（最大的一处）

旧口径 `oppQ = mean{ q(o) : o.pos > p.pos }` 有个隐蔽问题：
**对手池的大小随名次递减** —— 冠军面对「决赛第 2 名及以后所有人」（含大量分位很低的无名之辈），
季军只剩「第 4 名以后」。**名次越好，被平均的对手反而越弱。**

修正为「同场领奖台的其他人」后，对手池对三人对称：

| 指标 | 旧池 | 新池 |
|---|---:|---:|
| ρ(M6, M1 全量) | 0.174 | **−0.008** |
| ρ(M6, 领奖台条数) | −0.119 | **−0.290** |
| 官方 #1 落在单项目 M6 前 10 | 10/21 | **13/21** |

## 8 已知边界

1. **强度池只用单次成绩** —— 平均轨的对手强度实际是用单次成绩衡量的。
2. **分位法把「同池内相对位置」当作强度** —— 池子极小时（如 1982 年三阶只有 19 人）分位不稳定。
3. **210 个基线 cell 的样本量 ≤ 3** —— 这些格的基线是弱估计。
4. **对手池是「同场领奖台」** —— 若某场只有 1 人进决赛，无对手，excess 记 0。
5. **时代归一自建历史分位** —— 官方 `ranks_*.tsv` 是现势快照，不能用（用它的版本与本版 Top50 只重叠 23/50）。
6. **负分占多数** —— 进六维总分前必须归一化（秩变换 / 分位数 / 加权合成）。

## 9 定稿口径

```
M6_i = Σ_r excess(r) × w(r)
  excess(r) = oppQ(r) − median{ oppQ : 同(项目, 年代, 赛级) }
  oppQ(r)   = mean{ strength[o|event|year] : o 是同场领奖台的其他人 }
  strength  = 该选手在 (项目, 年代) 池内的成绩分位（归一后 lower=better）
  w(r)      = 冠军 1 / 亚军 0.6 / 季军 0.4

  聚合不乘 n^±α；无对手时 excess = 0
```
