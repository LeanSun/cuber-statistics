## 一、P0-1　`G` 奖励的是「项目粗糙」，不是「竞争激烈」

这是整套模型最硬的内伤。

`credit = ln(v_前/v_后) × T/365` 里，`G` 度量的是**相对进步幅度**。但幅度大有两种完全不同的原因：

1. 该项目竞争极激烈，要压过一堆顶尖选手才能挪动一点点 → **幅度小**；
2. 该项目没人玩、纪录还离物理极限很远，随便练练就能砍掉三成 → **幅度大**。

现在的公式对第 2 种发更多分。这不是理论担忧，实测就是这样。

### 先看 `G` 到底怎么算

一张**阶梯** = 一个项目、一个级别的一张榜（例如「四盲单次世界纪录」）。
把这张榜上的全部纪录提交按时间排好，再**按选手切段** ——
一个选手从抢到纪录、到自己被打破，算一段。每段一个 `G`：

```
G = ln( 前一位选手留下的成绩 ÷ 本段结束时自己最好的成绩 )
```

四盲单次的真实阶梯（共 13 段）：

| # | 段首 | 选手 | 段内最好 | G | 段长(天) |
|---|---|---|---|---|---|
| 1 | 2003-08-23 | Dror Vomberg | 19:54.00 | 12.65% | 1077 |
| 2 | 2006-08-04 | Chris Hardwick | 6:20.96 | 114.24% | 855 |
| 3 | 2008-12-06 | Ville Seppänen | 6:05.21 | 4.22% | 105 |
| 4 | 2009-03-21 | Chris Hardwick | 4:46.19 | 24.38% | 301 |
| 5 | 2010-01-16 | Ville Seppänen | 4:42.34 | 1.35% | 378 |
| 6 | 2011-01-29 | Feliks Zemdegs | 3:37.80 | 25.95% | 182 |
| 7 | 2011-07-30 | Daniel Sheppard | 3:17.41 | 9.83% | 349 |
| 8 | 2012-07-13 | Marcell Endrey | 2:30.62 | 27.05% | 673 |
| 9 | 2014-05-17 | Oliver Frost | 2:02.75 | 20.46% | 903 |
| 10 | 2016-11-05 | Kaijun Lin (林恺俊) | 1:34.66 | 25.99% | 559 |
| 11 | 2018-05-18 | Stanley Chapel | 1:29.42 | 5.69% | 43 |
| 12 | 2018-06-30 | Kaijun Lin (林恺俊) | 1:26.41 | 3.42% | 301 |
| 13 | 2019-04-27 | Stanley Chapel | 51.96 | 50.86% | 2728 |

第 3 段拆开算：

```
前一位 Ville Seppänen 留下   4:42.34 = 282.34 秒
本段 Daniel Sheppard 推到     3:17.41 = 197.41 秒
G = ln(282.34 / 197.41) = ln(1.4302) = 0.3578  →  35.78%
```

**「中位 G」= 把该项目全部段的 `G` 排序后取中间值。**
四盲 6 段排序后是 1.35% / 3.42% / 4.22% / 5.69% / 9.83% / 12.65% / 20.46% / 24.38% / 25.95% / 25.99% / 27.05% / 50.86% / 114.24%，
中位 = **20.46%**。

> **一处更正**：本文初版把单次轨与平均轨的 `G` 混在一起取中位，
> 于是「四盲只有单次」与「三盲：单次 16 段 + 平均 20 段」变成苹果比橘子，
> 三盲被算成 3.99%。分轨后三盲是 **10.39%**，四盲对三阶的倍数从「9 倍」修正为 **4.0 倍**。
> 以下所有数字均已按分轨重算。

### 为什么这个指标测错了东西

三个项目的守擂压力几乎一样，`G` 却差三倍多：

| 项目 | 每年被破 | 中位 G | 相对三阶 |
|---|---|---|---|
| 三阶 | 1.9610 次 | 5.14% | 1.0000× |
| 二阶 | 2.8508 次 | 17.11% | 3.3291× |
| 金字塔 | 2.8620 次 | 14.23% | 2.7685× |

三者守擂压力在 1.96 ～ 2.86 次/年之间（只差 46%），
但中位 `G` 差 **3.3 倍**。

如果 `G` 真是「难度」的度量，三个几乎一样难守的项目不该差三倍。
**差的那部分，是「这个项目的纪录还离物理极限多远」。**

全项目相关系数：`r(每年破 WR 次数, 中位 G) = -0.4349`。换口径重算：

| 口径 | 项目数 | Pearson | Spearman |
|---|---|---|---|
| 全部项目（含停办） · 中位 G | 20 | -0.4349 | -0.4316 |
| 全部项目（含停办） · 均值 G | 20 | -0.4419 | -0.4571 |
| 排除 4 个停办项目 · 中位 G | 17 | -0.4377 | -0.5000 |
| 排除 4 个停办项目 · 均值 G | 17 | -0.4923 | -0.5539 |

**四种口径全部为负**，排除停办项目后 Spearman 到 -0.5000。
即：**越容易被破的项目，`G` 反而越大。方向是反的。**

中位 G 的跨项目极差 **6.8 倍**（3.00% 四阶 ↔ 20.46% 四盲），
而「每年被破次数」的极差只有 **3.7 倍**。两者相差 **1.8 倍**，方向还相反。

### 把项目系数 `w_e` 也算上，仍然不对

`js/calc.js` 里确有项目系数（三阶 1.00、二阶 0.92、四盲 0.80…），一起算：

| | 三阶 | 二阶 | 四盲 |
|---|---|---|---|
| `w_e` | 1.00 | 0.92 | 0.80 |
| 中位 G | 5.14% | 17.11% | 20.46% |
| **G × w_e** | **5.14** | **15.75** | **16.37** |
| 相对三阶 | 1.00× | **3.06×** | **3.18×** |

`w_e` 只把四盲从 4.0 倍压到 3.2 倍 —— 压的正是 0.80 ÷ 1.00 那 20%，没有更多。
而一条**二阶** WR 仍然值 **3.06 条三阶**，且二阶的守擂压力还比三阶低。

原因很简单：活跃项目的 `w` 量程是 1.00 → 0.77，全区间只有 **1.30 倍**（含停办项目也只有 1.72 倍）；
而中位 G 的量程是 6.8 倍。**用 1.30 倍的刻度去修 6.8 倍的差距，刻度不够。**

### 而且：占有段引擎根本没接 `w_e`

`runs.js` 的 `scoreRuns()` 结尾是：

```js
const v = c.credit * gL * rho * f;   // 四个因子，没有 w_e
```

**条数口径（`m1.js` + `weightedSum`）会乘项目系数，占有段口径（`runs.js`）不乘。**
一旦按占有段口径上线，上面的 3.2 倍会原样退回 4.0 倍。这是接线上必须先补的一环。

### 后果：统治三阶不如统治金字塔

按累计 `G`（该项目全部 WR 段的 `G` 之和 = 该项目能兑现的总分上限）排序：

| 项目 | 累计 G |
|---|---|
| 五盲 | 6.310 |
| 脚拧 | 5.686 |
| 金字塔 | 5.636 |
| 二阶 | 5.611 |
| 三盲 | 5.568 |
| 四盲 | 5.089 |
| 魔表 | 4.929 |
| 斜转 | 4.838 |
| **三阶** | **3.953** |

三阶是魔方的核心项目，但按这套口径，**统治三阶 WR 二十年，拿到的分只有统治五盲的 63%**。

### 修法（已落地，见 `M1_项目定价.md` 与 `M1_项目权重v2.md`）

结论先说：**不是把 `w_e` 的量程拉大，而是让 `G` 不再跨项目。**

```
r      = min( G / G_ref(e), R_CAP )     // 项目内相对强度，典型段 = 1.0
score  = r × T/365 × w_e × V_L × ρ_s × f_L
```

归一之后，含金量只由 `w_e` 决定，三阶 `1.00` 是全体 21 个项目里唯一的最高值 ——
**这是结构保证，不依赖 G 的实测分布**。推导、单价表与前后对比见 `etl/score/M1_项目定价.md`，
硬约束写成 `test_runs.js` 的 [7][8][9][10] 四项断言。

### 三条候选修法的去留（留档）

**A. 项目竞争密度折价 `ρ_e^α`（已否）**

```
credit(R) = G × (T/365) × ρ_e^α        ρ_e = 该项目活跃选手数 / 全部活跃选手数
```

`α` 取 0.3～0.5。取 0.5 相当于「按参赛人数开根号」，和现行 `ρ洲` 的线性做法刻意不同 ——
地区密度是「值不值得算」，项目密度是「难不难」，难度应该次线性。
需要 ETL 提供每项目的活跃人数（`evS` 已按项目分段，加一个全站汇总即可）。

**副作用要先想清楚**：`ρ_e^α` 会把冷门项目压到接近零，进一步强化「都去打三阶」的激励，
这与「鼓励项目多样性」直接冲突。所以 `α` 不能大，并且应当加一个地板，例如
`max(ρ_e^α, 0.25)` —— 让任何项目的 WR 至少值三阶 WR 的四分之一，不至于变成零。

这个地板值不值得设，取决于你要 M1 度量「世界级成就」还是「项目宽度」。前者不设地板，后者必须设。

**实测否掉的理由**：要把一条典型二阶 WR 压到三阶以下，α 需要约 **230**；
要压住金字塔需要约 **37**。α 是全局参数，取最大值才管用，于是整张 `w` 表全废。
根源是 `ρ_e` 分不开主流项目之间的竞争强度 —— 二阶活跃人数是三阶的 **0.995 倍**，
而两者的典型 `G` 差 3.3 倍。**这条路的量程不够，不是参数没调好。**

**B. 项目内归一（已采纳，但换了实现）**

```
G_norm = G / median_G(e)
```

把每个项目的 `G` 除以该项目的中位 `G`，于是「平均的一次突破」在所有项目都值 1.0。
简单、不需要新数据，但**把项目间的差异彻底抹平了** —— 三阶和金字塔的 WR 变成等价，
这又走向另一个极端。必须配合 `w_e` 才有意义，而 `w_e` 现在是外生拍定的。

**最终实现与这里有三处不同**（详见 `M1_项目定价.md`）：

1. 参考量用**算术均值**而不是中位 —— 只有均值才成立恒等式 `Σ(G/G_ref) = n`，
   即「任何项目的历史总信用 = 该项目的段数」，一个段在所有项目里完全同质；
2. 加 `R_CAP = 3` 截顶，防止长尾项目（SQ1 的 G 分布中位 3.05%、最高 82%）单段爆表；
3. 明确乘 `w_e`，并把 `w_e` 认定为**唯一**的跨项目价格 —— 三阶 1.00 恒为最高。

**C. 换度量：用排名而非成绩**

把 `v` 换成「当时该成绩的全球排名倒数」，`G = ln(rank_前/rank_后)`。
排名天然跨项目可比。但需要全量成绩表算历史排名，成本最高，且排名会随人数膨胀漂移。

## 二、P0-2　两轨按 1:1 相加，但这个 1:1 没有依据

`total = single + average`，两轨按 1:1 相加，价格完全一样。但数据显示它们不一样：

| 指标 | 单次轨 | 平均轨 | 差 |
|---|---|---|---|
| 纪录条数（6147 人合计） | 7416 | 8303 | 平均轨多 **12.0%** |
| 得分均值 | 0.168 | 0.183 | 平均轨高 **8.9%** |
| **每条单价**（×10⁻⁵ 分） | 2.2605 | 2.1987 | 平均轨每条低 **2.7%** |

条数多 12.0%，得分只多 8.9% —— 两条曲线不同步。
所以平均轨的**每条单价反而低 2.7%**。

### 真正的问题不是「谁更贵」，是「权重来路不明」

`total = single + average` 这个 1:1，隐含了一个没人验证过的判断：**单次和平均同等重要**。
但实际落到榜上，两轨的贡献是：

- 方差贡献 **44.6% / 55.4%**（本文开头诊断实测，N=4952）；
- 平均轨比单次轨高出 24.2%，这不是设计出来的，是「平均纪录更容易累积」的副产物；
- 结果：一个平均强、单次弱的人（Max Park 型）自动占到便宜，
  一个单次强、平均弱的人（爆发型）自动吃亏。**这不是价值判断，是记账误差。**

所以修法的目标不是「拉平单价」，而是**把两轨权重变成一个显式、可辩护的参数**。

### 修法：先标准化再相加

```
total = single / 0.168 + average / 0.183     // = 5.965·single + 5.477·average
```

等价于 `w_s : w_a = 1.089 : 1`。含义：**两轨各自除以全站均值，于是「1 分的单次」与「1 分的平均」代表同样的相对水平**。
这样两轨在中位数上精确等权，`total` 的零点也回到「一个平均水平的纪录选手」。

代价：`total` 的绝对数值不再是「原始分相加」，所有历史数字都要重算。
如果只想改权重不想改量级，用 `total = a·single + (1−a)·average`，`a` 由你定（默认建议 0.5，但要看你要不要给稳定性更高权重）。

若不想引入权重，另一个思路是 `total = max(single, average) + λ·min(...)`，
承认「不全面」的选手只该拿一部分 —— 但这是价值判断，需要你定，不是校准。

### 为什么不能干脆砍掉一轨

有人会说：既然两轨八成重叠，砍一轨不就完了。不行。

- 相关系数 `r = 0.8817`，`R² = 0.7774` —— 平均轨有 77.7% 的方差能被单次轨解释，
  反过来仍有 **22.3% 是独立信息**，不是纯冗余；
- 两轨相差 3 倍以上的人有 **578 / 4952（11.7%）**，这批人正是「爆发型」与「稳定型」的分野；
- 只有单次无平均 **981 人**、只有平均无单次 **683 人** —— 砍任何一轨，这两批人直接归零。

所以两轨都得留，要谈的只是**权重**。

## 三、P0-3　阶梯首段以「本人首次提交」为基准，白送分

`runs.js` 里：

```js
r.gain = i === 0 ? gainOf(r.subs[0], r.vOut) : gainOf(prevOut, r.vOut);
//                     ↑ 第一个段用「自己第一次破纪录的成绩」当基准
```

问题：阶梯上的第一段**没有前一位**，现在的做法是拿该选手自己的首次提交充当前人基准。
但这等于把他「从没经验练到自己最好」的进步全部算作「破纪录的贡献」，而这段进步本来是他自己成长的一部分，
不该算作「推动了人类极限」。

更合理的锚点有三种：

1. **外部基准**：该项目在该级别上的首个官方纪录之前的状态（若无，用一个固定的「初始门槛」）；
2. **零基准 + 固定首段分**：所有阶梯的首段一律给一个常量（比如 `wc` 条目的中位 credit），
   不让「谁先来谁占便宜」；
3. **只算相对第二名的优势**：首段 `G = ln(v_第2名最好值 / v_首段最好值)`，需要全量成绩表。

### 诚实标注：这一条无法用现有数据量化

样本里首段占 20.5% 的段、24.3% 的 credit，
但这个占比受 12 条截断影响，不能外推。这一条只能定性指出，不能量化。

## 四、P1-1　`T` 硬截 10 年，等于没有上界

段长实测：P50 = 328 天，P90 = 1785 天，P99 = 3696 天。

| 阈值 | 超过的段占比 |
|---|---|
| 1 年 | 46.3% |
| 3 年 | 20.1% |
| 5 年 | 9.5% |
| 10 年 | 1.1% |

`D_cap = 3650` 天只触及 1.1% 的段，**实际上等于没设上限**。
于是「守得越久越值钱」在 5～10 年区间没有任何约束，而那正是「没人来挑战」和「统治力强」最难分辨的区间。

### 修法：把硬截换成饱和

```
T_eff = D_sat × (1 − e^(−T / D_sat))        D_sat ≈ 4～5 年
```

性质：`T→0` 时 `T_eff ≈ T`（短期不折扣）；`T→∞` 时 `T_eff → D_sat`（长期自然封顶）；**处处连续可导，没有拐点**。
守 5 年拿 63%，10 年 86%，20 年 95%，永远不会「突然不值钱」。

实测对照：`D_sat = 5 年` 时全站 Σcredit 比硬截 10 年低 **30.3%**。
这个幅度不小，说明这一项确实在分配分数，不是无意义的细节。

`D_sat` 该定几年不能拍。正确的定法是看「守到第 N 年时，被打破的风险率还在不在明显上升」—— 用生存分析做，
拐点出现的位置就是 `D_sat`。这个可以等全量数据到位后一次做完。

## 五、P1-2　`f` 用注册人数代理竞争强度，是个脆弱的假设

`f_L(y) = ln(1+N_L(y)) / ln(1+N_L(基准))`。这个式子的地基是：**竞争强度 ∝ ln(注册人数)**。

两个问题：

1. **注册人数里绝大部分不是竞争者。** WCA 30 万注册者，真正长期活跃、能威胁纪录的是极小一撮。
   2003→2010 人数从几千涨到 5 万，但涨的多是「参加过一次就消失」的休闲玩家；
   2010→2020 从 5 万到 20 万，涨的同样多是休闲玩家，但**训练方法、器材、教学资源的进步是实打实的**。
   用总人数做代理，会把这两段的不同性质抹平。

2. **`ln` 的形状是错的。** 对数在 N 小时陡、N 大时平，于是「早期人数翻倍」被打成重折，
   「近期人数翻倍」几乎不折。如果竞争强度实际是次线性甚至接近线性增长，这套折算就系统性偏袒某个时代。

### 更好的代理：不数人，数成绩

```
f_L(y) = S_L(y) / S_L(基准)
S_L(y) = 该级别在 y 年的「第 100 名成绩」倒数（或前 1% 门槛）
```

直接可测、不需要假设。要进前 100 需要多快，天然包含人数、训练、器材的复合效应。
数据成本：需要全量成绩表按年算分位数 —— 和「全量阶梯导出」是同一批数据，可以一次做完。

**在这一项改掉之前，所有跨时代比较都应该标注「依赖 ln(人数) 假设」。**
现在 `Feliks_vs_Max.md` 里 1.130× 这个数，实际上是两个假设的乘积：`ln(人数)` 假设 + 条数口径。

## 六、P1-3　只赢时间的并列记 `G=0`，时间价值被整段丢弃

多盲和最少步里，「主指标相同、只赢时间」是常态。现在这种情况 `gain = 0`，于是

```
credit = 0 × (T/365) = 0
```

这位选手守了多久都拿不到分。真实样本：2009-04-25 Kai Jiptner 用 `10/10 42:06` 破 Dennis Strehlau 的 `10/10 44:09`，
同分快 2 分钟，`G = 0`，整段归零。

样本里 `G = 0` 的段占 12.2%（同样受截断影响，真实值更高）。

### 修法：给次级 `G`

```
if (主指标相同 && 时间更短)
    G = λ × ln(t_前 / t_后)          λ ≈ 0.3
```

`λ < 1` 是因为时间不是主指标，不该和成绩进步同价。但它至少有值，不会归零。
这个改动只影响多盲 / 最少步，对总分盘子影响很小，但**在项目内部是公平性问题**。

## 七、明确不建议改的

评审要能说「这里不用动」。以下三项看着可疑，但都是**已经拍过板的价值选择**，不是模型缺陷：

| 项 | 看着像问题 | 为什么不改 |
|---|---|---|
| CR/NR 系数只有 0.40/0.15 | 洲纪录太便宜 | 你选的是 A 方案「M1 只认世界级」。改了就变成 M1 度量地区成就，与设计意图冲突 |
| ρ 线性不开根号 | 小国刷分 | 开根号会让小国纪录变贵，正是你要防的方向 |
| 一条纪录只归最高级 | Feliks 的 NR 被 CR 吃掉 | 这是防重复计分的正确设计。改成可叠加会让「既是 WR 又是 NR」白拿两份 |

另外「属地口径 vs 级别口径」不是模型问题，是数据问题：
`held` 是按级别算的，切属地口径需要 ETL 重算，不改变模型逻辑。

## 附：本评审的数据边界

- 条数类统计用 `mCalc.rec`：6147 人（detail 层），**全量精确**。
- 段类统计用 `records` 逐条：同样 6147 人 × 上限 12 条 → 4822 个级别阶梯、25270 段（可核算 18510）。
