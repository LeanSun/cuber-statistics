## 一、机制

### 1.1 阶梯

一条**阶梯** ℓ = (项目 e, 轨道 t, 级别 L, 属地 s)：

| 级别 L | 属地 s | 例 |
|---|---|---|
| WR | 全球 | 三阶单次世界纪录 |
| CR | 该洲 | 三阶单次大洋洲纪录 |
| NR | 该国 | 三阶单次澳大利亚纪录 |

阶梯上是按时间排好的、被 WCA 承认的全部纪录提交 `r₁ … rₙ`，成绩单调变好。
一个成绩只会出现在**一张**纪录表上（是 WR 就不会再出现在 CR 表里），所以三级之间天然不重复计数。

### 1.2 切段

把提交序列按选手切：连续同属一人的若干提交 = 一个**占有段** R。

```
  r₁      r₂ r₃        r₄        r₅   r₆
  │        │  │         │         │    │
──●────────●──●─────────●─────────●────●──────▶ t
  └──────────── 段①（A 的）────────┘  │
                          ▲           └── 段②（B 的）
                          └─ 被 B 打破，段①在这里封口
```

```
τ_start = r₁ 的日期      ← 本人第一次拿下这条纪录
τ_end   = r₅ 的日期      ← 别人打破它的那天（不是本人最后一次刷新的那天）
```

**这是整个机制的关键**：`τ_end` 由别人的成绩决定。本人刷 1 次还是刷 10 次，都改不了这个日期。
所以「多刷几次」不是被扣分，而是**根本没有可以拿分的空间**。

### 1.3 段的价值

```
G(R)      = ln( v_前一位留下的值 / v_段内最好值 )
T(R)      = τ_end − τ_start                          （天）
credit(R) = G(R) × min(T(R), D_cap) / 365            单位：对数进步量·年
```

`G` 只认「比前一位领先多少」。段内从 9.40 刷到 9.25 再到 9.00，
按 `ln(9.50/9.00)` 一次算完；中间那两步不单独计价 —— 它们本来就是这个乘积的因子。

### 1.4 「除以 365」不是「只算一年」

这一点必须先说清，否则容易被读成「还在用 1 年窗口」：

| 写法 | 含义 |
|---|---|
| `min(T, 365)` | **截断**到一年 —— 这才是 1 年窗口，本文不用 |
| `T / 365` | **单位换算**：把「天」写成「年」。守 2000 天就是 5.48 年，一分不少 |

真正会截断的只有 `D_cap`，它是安全阀不是窗口，取值见 §六。

## 二、五条性质

### 2.1 拆分中性：段内刷 k 次 = 刷 1 次

段内 k 次提交 `v₀ → v₁ → … → v_k`，对数进步望远镜求和：

```
G = ln(v_prev / v_k) = Σ ln(v_{j−1} / v_j)
```

`k` 只增加这个和的**分项个数**，不改变**和本身**；`T` 从 `τ_start` 起算，也不随中间刷几次变化。
于是 `credit` 与 `k` 严格无关 —— `k` 压根没进公式。

实测（§四）：64.9% 的段本来就是一次到位，
15.8% 的段刷了 3 次以上。
旧口径按条数逐条给分，等于给「爱刷」的选手发到「一段一分」的 **1.68 倍**。

### 2.2 被打破即停

`τ_end` 取**下一位不同选手**的首次提交日。本人再刷，`τ_end` 不动；
想让段变长只有一个办法：守到别人破不了。那正是我们要奖励的事。

### 2.3 回归重算

被抢走后再次拿下：`G` 以「抢走者留下的值」为基准，`T` 从抢回日重新计时。
旧段的时长不结转，也不会因为「他曾经拥有」而给折扣或加成。（§七 有真人样本：波兰那条阶梯里三个人都回归过。）

### 2.4 三级一致

| 级别 | 阶梯怎么切 | 竞争密度 ρ | 时代折算 f |
|---|---|---|---|
| WR | 全球一条 | 1（不折） | 全球累计注册人数曲线 |
| CR | **每个洲一条** | 该洲人数 ÷ 300,616 | 该洲人数曲线 |
| NR | **每个国家一条** | 该国人数 ÷ 300,616 | 该国人数曲线 |

「按洲切、按国切」不是特判，是属地 s 决定的：一条 NR 阶梯上只有本国选手，
所以下一位打破者一定是本国人 —— 机制自动成立，三级不需要写三套代码。

### 2.5 阶梯守恒律

一条阶梯上，所有段的 `G` 之和恒等于首尾总进步：

```
Σ G(R_i) = ln( v_首 / v_末 )        与怎么切段无关
```

推论：

1. 换人、拆人、抢回来，都只是把同一个总进步量在选手之间**重新分配**，不能凭空变多；
2. 每人拿到的份额 = 他的 `G` 占总进步的比例 × 持有时间权重 `T/365`；
3. 整条阶梯的总分有硬上界 `ln(v_首/v_末) × max(T)/365 × 系数`，参与者再多也不膨胀。

§七 在真人阶梯上实测校验了这条恒等式。

## 三、把你原来的问题算一遍：4 次 vs 1 次

设定：前一位留下 9.50，本段最终到 9.00（总进步 5.26%），总持有期 365 天。
A：一年里分 4 次推进，每次守 3 个月；B：一次到位，守满一年。
两者**同属一个占有段**（中间没人打破），所以 `τ_start`、`τ_end`、`G` 全都相同。

| 口径 | 4 次 × 3 个月 | 1 次 × 12 个月 | 比值 | 判定 |
|---|---|---|---|---|
| 条数（现状） | 4 | 1 | **4:1** | 错，按手续次数给分 |
| 按条面积（上一稿） | 0.0135 | 0.0541 | 1:4 | 罚过头：把段内自刷当成 4 次独立持有 |
| **占有段（本文）** | **0.0541** | **0.0541** | **1:1** | 对，k 不进公式 |

占有段口径下两者**严格相等**，不是「差不多」：

```
G      = ln(9.50 / 9.00) = 0.0541
T      = 365 天 = 1.000 年
credit = 0.0541 × 1.000 = 0.0541     两种打法都是这个数
```

> **一处自我更正**：上一稿说面积口径下「4 次」只有「1 次」的 62.5%，那个数是把「累计幅度」
> 误当成「单条幅度」算出来的。按单条幅度老实算，4 次会只剩 1/4（上表第二行），
> 方向对但罚得过重。占有段口径把 `k` 彻底消掉，落在两者之间，正好是 1:1。

再补几种「守多久」，确认时间真的进公式、但只由事实进入：

| 情形 | G | T(天) | credit | 说明 |

## 五、多盲与最少步

### 5.1 规则

| 项目 | 主指标（定名次） | 次指标（主指标相等时） |
|---|---|---|
| 三阶多盲 333mbf | 得分 = 成功数 − 失败数 = 2×成功 − 尝试 | 用时，短者优先 |
| 三阶最少步 333fm 单次 | 步数，少者优先 | 用时，短者优先 |
| 三阶最少步 333fm 平均 | 三次平均步数 | 用时，短者优先 |

所以多盲不能当秒表处理。引擎里的对应关系：

```
cost  = −得分                   统一成「越小越好」
tie   = 用时                     仅在 cost 相等时才比
G     = ln( (得分_新 + 10) / (得分_旧 + 10) )
```

`+10` 是平滑项：得分为 0 或很小时 `ln(得分)` 会炸掉，加 10 分的先验压住它；
常规区间（30–50 分）里几乎不改变幅度：40→41 是 1.98%，不带先验是 2.47%。

### 5.3 一个必须单独处理的细节：只赢在时间的突破

多盲里「同分但更快」也是合法的破纪录，它**会终结**前一位的占有段；
但它对纪录水平的推进是 0，所以 `G = 0`。
引擎把这两件事分开：`isBetter()` 用（主指标, 次指标）的字典序判断「是否破纪录」，
`gainOf()` 只用主指标算幅度。

真实样本：**2009-04-25 Kai Jiptner** 用 `10/10 42:06` 打破了 Dennis Strehlau 的 `10/10 44:09` —— 
得分都是 10 分，只快了 2 分钟。
这一条 `G = 0`，但它照样把 Dennis Strehlau 的段封了口。

这是对的：他确实抢走了纪录，但没有把人类极限推得更远。

## 六、D_cap 取多少

`D_cap` 只防一种病：**没人竞争的地方，一条平庸纪录能守十几年**（停办的脚拧、八板，或全国只有几十人的小国）。
它不是窗口，正常纪录不该碰到它。

| 候选 | 触及段的占比 | 评价 |
|---|---|---|
| 365 天（1 年） | 36.39% | 这就是 1 年窗口，已否决 |
| 1095 天（3 年） | 14.39% |  |
| 1826 天（5 年） | 6.78% |  |
| 3650 天（10 年） | 0.67% | **采用** |
| 7300 天（20 年） | 0.00% |  |

取 **3650 天（10 年）**：只触及 0.67% 的段，
正常竞争出来的纪录一条都碰不到顶，被削平的只有「无人区烂纪录」。

要更平滑可以把 `min(T, cap)` 换成 `D_cap·(1 − e^(−T/D_cap))`，没有硬拐点；
但硬截顶更好解释、更好审计，本文采用硬截顶。

**守恒校验**：Σ G = 0.4722；ln(首值/末值) = ln(18.60/11.60) = 0.4722。两者相等。
切段只改变「谁拿多少」，不改变「一共有多少」。

两处值得单独看：

- **第 5 段（Tomasz Żołnowski，段内 2 次）**：13.36 → 12.32，一条段。
  旧口径给 2 分，新口径给 0.0366；如果他一次做到 12.32，新口径**还是** 0.0366。
  真人样本上，拆分中性成立。
- **第 0 段（首创）**：没有前一位可参照，`G` 记 0。这是刻意的：首创只能证明「第一个到」，
  不能度量「推得多深」。影响面是每条阶梯 1 条纪录。

⚠️ **末段是开放段**：Tomasz Żołnowski 的 11.60 算出来 6643 天，
十几二十年没人破波兰三阶平均 NR 显然不成立。真实原因是这一段之后的纪录没进样本
（后来那些 NR 得主多半同时是 CR/WR，不进 NR 表；即便进了，也被「每人只留 12 条」截掉了）。
**开放段必须隔离**，不能拿去做统计或排名 —— §四 的所有数字都只统计闭合段。

## 八、公式卡

```
M1(p, e, t) = Σ_{R ∈ p 的占有段}  G(R) × min(T(R), D_cap)/365  ×  V_L  ×  ρ_s  ×  f̄_L(R)

G(R)   = ln( v_前一位留下的值 / v_段内最好值 )      ← 段内刷几次都不变
T(R)   = τ_end − τ_start                            ← τ_end = 别人打破那天
V_L    = WR 1.00 / CR 0.40 / NR 0.15                ← 沿用已定稿
ρ_s    = 该洲(国)全量人数 ÷ 300,616                  ← 沿用已定稿
f̄_L(R) = f_L 在该段区间内的月均值                    ← 沿用已定稿，改为区间均值
D_cap  = 3650 天                                     ← 安全阀，非窗口
```

总计 = 单次轨道 + 平均轨道；乘项目系数 `w_e` 后累加。
除 `G`、`T` 之外，级别价值、竞争密度、时代折算三项与上一版完全一致，可以逐项对照。

## 十、还没解决的问题

1. **全量阶梯**（第 1、2 项）。当前每人只有 12 条，Feliks 的 356 条只剩 12 条。
   所以本文**不给任何排名结论** —— 名次必须等全量阶梯重建后才有意义。
2. **项目内归一**。`G` 是可直接相加的对数比，但各项目「典型突破幅度」差约 5 倍
   （盲拧早期一次能推进 10%，七阶只有 2%）。裸 `G` 会让盲拧类系统性占优，
   聚合层需要再除一个「该项目段内 G 的中位数」。
3. **属地口径切换**（§4.4）。等全量阶梯落地后，改成「本国人拿 CR/WR 也算打破 NR」，
   更贴近事实，届时需要重算一次 `held`。
4. **`f̄` 用区间均值是否合适**。段分是随时间均匀累积的，均值比「取段中点」更对；
   但与旧版「按年份条数加权」不同，切换时会有小幅漂移，需要重新标定一次。
5. **`D_cap` 的平滑版**。硬截顶在 10 年处有拐点；若日后发现 8–12 年有实际案例聚集，改饱和函数。
6. **名次复核（含 Feliks 是否仍第一）**。口径换了乘数，名次必须重算，本文不做这个结论。
   定性上可以说的是：排序的主要驱动项没有变 —— 一条 WR 仍然远贵于一条 NR（澳洲约 160 倍，小国上万倍），
   而「段」只是把「一条」换成 `G×T/365`。以 Feliks 的纪录结构（121 条 WR、集中在三阶到七阶、
   多次长期保持），他的相对位置不会因为「不再数条数」而下降 —— 但这话必须等全量阶梯跑完才能落实成数字。
