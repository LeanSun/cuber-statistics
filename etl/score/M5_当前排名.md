# M5 纪录比（Kinch）

> 生成脚本 `etl/score/m5_current_rank.js`｜数据快照 **2026-10-15**｜WCA 导出 **v2.0.2 / v288**
> 口径：**M5-KINCH（2026-11-04 定稿）** —— 全权替换旧 M5-F3 分段比值。

## 0 一句话

**M5 = 你在每个项目上「离世界纪录有多远」的平均值。**

单事件得分 = 100 × 世界纪录 / 你的 PB（WR 持有者 = 100，慢一倍 = 50）；
总分 = 所有**现役 17 个项目**的**算术平均**，没参赛的项目记 0。
→ 理论满分 100（需全项目 WR），偏科者会被明显压低，是「全能榜」口径。

## 1 公式

```
M5 = (1/N) × Σ_e 100 × WR_e / PB_e

  e     = 现役项目（每项目按 Kinch 官方规则只取一条轨，见下）
  WR    = 该项目所选轨道的世界纪录（多盲按 decodeMulti 折成 cost）
  PB    = 个人最好（多盲同口径）
  N     = 现役项目数 = 17（停办项目不计）
  缺项  = 该项目没成绩 → 计 0，但仍占分母 N
```

- 停办项目（`333ft` / `magic` / `mmagic` / `333mbo`）整体不计分；
- **选轨规则（与 wca.cuber.pro 一致）**：多盲 `333mbf` / 四盲 / 五盲只有单次榜 → 取 single；
  三盲 / 最少步 → 单次与平均**取较优**；其余 12 项 → 取 average；
- **单轨独立榜（§3b）不套用上述选轨**：单次档只取 `ranks_single`、平均档只取
  `ranks_average`，分母仍是 17 个现役项目（没有该轨成绩的项目记 0）；
- 与旧 M5-F3 的差别：旧版 1000 分制 + 按项目标定 D0 + 前1%拉伸/长尾压缩 + 加权求和；
  新版 100 分制 + 纯 WR/PB 比值 + 每项目单轨等权平均（分母 17，不是旧双轨口径的 33）。

## 7 已知边界

1. **官方 ranks 是终身 PB 榜**：Kinch 口径同样基于 PB，退役者的 PB 未被超越就仍计入；
   这是 Kinch 的原味，不引入时间衰减。
2. **历史快照** 由 `m5_facts.js` 按「截至年末」的 WR/PB 逐年重算，语义一致；
   历史年份为控体积只保留各组合前 100（最新年份全量），长尾人物的历史均值会略偏低。
3. **`fto`（八面体）** 官方 ranks 无数据，不参与。
4. **`333mbf`** 只有单次榜，按规则取单次。
