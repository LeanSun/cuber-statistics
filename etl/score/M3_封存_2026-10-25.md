## 0 一句话说清 M3 是什么

**M3 = 一个人在锦标赛上「把纪录往前推」这个动作的总量**，与 M1「持有多久」完全独立：M1 奖励**守**，M3 奖励**破**。同一条 WR 在 M1 计一次持有价值、在 M3 计一次突破动作，两者并存不冲突。

## 1 计分公式（唯一权威）

```
M3 = Σ_该选手所有「锦标赛破纪录条目」 [ W_REC[纪录级别] × W_TIER[赛事级别] × f(年,项目)^ERA × PIO_W? ]

  W_REC  = { WR: 1.0, CR: 0.4, NR: 0.15 }     # 镜像 M1 的级别价值常量
  W_TIER = { WC: 1.0, CC: 0.6, NC: 0.4 }      # 世锦赛 > 洲锦赛 > 国锦赛
  f(y,ev) = min( 1, ln(1 + N(y,ev)) / ln(1 + base(ev)) )
      N(y,ev)   = 第 y 年、第 ev 项的**活跃选手数**（该年有成绩的 pid 去重）
      base(ev)  = max_y N(y,ev)，即该项目**历史峰值**活跃人数
  ERA     = 1（默认，标准 f）；0.5 = 温和 √f；0 = 关闭
  PIO_W   = 0（默认，开荒不计分）；1 = 退回旧口径
```

**条目认定规则（全部固化，不得自由裁量）：**

| # | 规则 | 说明 |
|---|---|---|
| R1 | 适用范围 | 仅 **锦标赛**：WC 世锦赛 / CC 洲锦赛 / NC 国锦赛。**普通赛（OP）不计** |
| R2 | 纪录级别 | **WR / CR / NR 三级全计** |
| R3 | 轨道 | **单次(single) 与 平均(average) 各计一次** |
| R4 | 去重 | 同一比赛 + 同一项目 + 同一类型 + 同一级别，**多轮次只计一次**；去重键 `pid|comp|ev|type|level` |
| R5 | 时代折算 | **做**。单条加分 `×= f(年,项目)^ERA`。`f = min(1, ln(1+N(y,ev)) / ln(1+base(ev)))`，N = 该年该项目**活跃选手数**（去重 pid），`base(ev)` = 该项目**历史峰值**活跃人数（活跃项目即最新年；停办项目取鼎盛年，避免「无未来基准 → f≡1」的漏洞）。可调 `--era=<0..1>`，**默认 1（标准 f）**；0.5 = 温和 √f；0 = 关闭。**2026-11-01 用户拍板** |
| R6 | 属地门槛 | **不受 S5 约束**（M2 的「客场折半/属地门槛」只作用于 M2 领奖台分）。破纪录是客观成就，**客场破纪录照样计** |
| R7 | 名次门槛 | **不要求领奖台**。非前三名选手在锦标赛上破纪录，同样计分 |
| R8 | **开荒不计分** | 若该条目是某（范围, 项目, 轨道）**历史上第一条成绩**，则它是「第一个记录」而非「打破纪录」，**不计分**。范围随级别变化：**WR 看全球线、CR 看选手所属洲、NR 看选手所属国家**。判定用 `比赛日期 + 结果id` 组成的 seq，与该范围的「首条成绩」边界比较（`seq ≤ 边界` 即开荒）。2026-10-31 用户拍板，可调 `--pio=<0..1>`，默认 **0**（完全不计） |

## 3 关键决策（用户拍板 + 实证）

| # | 决策 | 依据 |
|---|---|---|
| D1 | **与 M1「持有纪录价值」独立并存**，不重算持有，只奖突破动作 | 用户 2026-10-25 明确。M1 问「守了多久」，M3 问「推得多猛」，两者是不同成就 |
| D2 | **仅锦标赛 WC/CC/NC**，普通赛不计 | 大赛破纪录。顾影洲/普通赛的破纪录含金量低得多 |
| D3 | **WR + CR + NR 全三级** | 与 M1 的三级结构保持一致；否则洲/国家纪录在锦标赛上的突破完全不计，会系统性抹掉小国选手 |
| D4 | **单次与平均各计一次，同场同项目同类型去重** | WCA 的锦标赛常有 5 轮/6 轮，若不去重会按轮次线性刷分 |
| D5 | ~~不做时代折算~~ → **做时代折算（标准 f）**（2026-11-01 用户拍板） | 原依据是「破纪录是离散事件，按年代打折会与 M1 的 `f_L` 重复计分」。**实证推翻该依据**：2003 年全球仅 90 名活跃选手却产出 72 条锦标赛纪录，2026 年 52,166 人仅产出 505 条（每万人产出差约 82 倍）；2003 年 555 项目全球仅 15 人、盲拧 3 人、最少步 2 人 —— **竞争者只有个位数时，「破纪录」与「击败一个人」等价**。不折算等于放任早期选手 M3 通胀。**与 M1 的 `f_L` 双重打折是有意为之**：只在一个维度校正，另一个维度就会成为漏洞 |
| D6 | **不受属地门槛约束** | 客观成就不该因「客场」打折。且 M3 是独立维度，若再套 S5 会与 M2 的 K 折半重复惩罚同一事实 |
| D7 | **非领奖台也计** | 只奖前三会漏掉「进了决赛但没进 podium 的破纪录者」，也让 M3 退化成 M2 的子集 |
| D8 | **开荒（首条、无前值）不计分**（2026-10-31 用户拍板） | WCA 纪录标记的含义是「该成绩成为当时的当前纪录」。当某范围此前**没有任何成绩**时，第一个录入的成绩会自动成为 WR/CR/NR —— 它前面没有人可以打破，因此不构成「突破动作」（见 R8）。实证：2003 年世锦赛 11 条 WR 属开荒（当时 555 项目全球仅 15 人参赛、盲拧仅 3 人、最少步仅 2 人）；1982 年 Minh Thai 的 22.95 亦属此类，其 M3 由 1.00 归 0 |
| D9 | **时代折算分母用「项目历史峰值」`base(ev) = max_y N(y,ev)`，不用固定基准年**（2026-11-01） | 若取最新年作分母，magic / mmagic / 333mbo 等**停办项目** N=0 → f≡1，早期纪录反而逃过折算。取峰值后：活跃项目等价于最新年、停办项目取其鼎盛年，漏洞闭合 |

## 8 已知边界（不修，但别当 bug 再报）

1. **`country_id` 存的是国家名而非 ISO2**。WCA v2 导出的 `persons.country_id` / `competitions.country_id` 实际是**国家全名**，必须先经 `countries.tsv` 的 `isoOf` 映射成 ISO2 再比较。诊断脚本若直接大写国家名做属地比对，会把全部 CC/NC 误判成客场（主脚本 `m3_record_bonus.js` 始终正确，已修）。
2. **原始标记 13149 → 去重 12528**，差 621 条是「同场同项目同类型多轮次重复」，属正常去重。
3. **不排名次门槛**是有意为之（D7），不是漏算。
